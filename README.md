# PNG Transparenter Studio

Geminiなどの画像生成AIで作成した「黒背景のTシャツデザイン（イラスト・ロゴ）」から、**デザイン内部の黒色（黒線・サングラス・影・文字など）を残したまま、外側の背景だけを綺麗に透過PNG化する**Webアプリケーションです。

## 主な機能

- **外側＋タップ箇所のみ透過（Flood Fill / 境界追跡方式）**
  - 画像の外周から連続している黒背景のみを自動透過し、イラスト内部の黒色を保護します。
  - 文字の「O」「A」の内側など、孤立している黒背景は**「タップで穴抜き」**ツールでワンタップ追加透過できます。
- **Tシャツ印刷向けの境界補正（白Tシャツでの黒フチ残り対策）**
  - **許容度（しきい値）調整**：わずかなノイズを含む黒背景も柔軟に透過
  - **境界のなめらかさ（ソフトエッジ）**：ジャギーのない自然なアンチエイリアス処理
  - **フチ削り（1〜4px収縮）＆色かぶり除去**：白や淡色のTシャツにプリントした際に目立つ「黒いフチ残り」を除去
- **手動ブラシ補正（消しゴム / 復元ブラシ）＆ Undo / Redo**
- **Tシャツ生地カラー＆着用モックアッププレビュー**
  - 白・黒・グレー・ネイビー・レッド・ベージュなどの仮想Tシャツ生地色や、Tシャツシルエット上での着用イメージをリアルタイム確認
- **Gemini用プロンプト作成支援**
  - 透過しやすいTシャツデザインをGeminiで生成するためのプロンプトをワンクリック作成

## ローカル開発・ビルド手順

```bash
npm install
npm run dev     # 開発サーバー起動
npm run build   # 本番ビルド (dist/ に出力)
```
